# Security Policy

## Reporting a vulnerability

Please do not disclose security issues publicly in issues, PRs, or discussions.

Use GitHub's private vulnerability reporting:
- Open the repository
- Go to the Security tab
- Choose "Report a vulnerability"

If private reporting is not available, contact the repository maintainer through a private channel and do not share details in public.

## Supported versions

The project is actively maintained on the default branch. Security fixes are prioritized for the current branch and the latest release candidate.

## Response expectations

- Acknowledge receipt as soon as possible
- Provide triage status and next steps
- Ship a fix or mitigation for confirmed vulnerabilities promptly

## Safe disclosure practices

- Do not open public issues for vulnerabilities
- Do not commit secrets, credentials, tokens, or private environment data
- Do not share reproduction details publicly before a fix is available
